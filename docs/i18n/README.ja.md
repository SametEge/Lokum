**Lokum**（ロクム）は Mozilla Firefox をベースにした、トルコの伝統菓子ロクムの味わいの
ウェブブラウザーです。すでに信頼しているエンジン、セキュリティ、拡張機能をそのまま
受け継ぎ、Arc 風のサイドバー、手作業で調合した 12 種類のカラー「フレーバー」、
スペース、コマンドパレット、やさしいアニメーション、そして驚くほど丁寧な初回
セットアップで包み込みました — 12 の言語で。新しいバージョンができると、GitHub
Releases から静かに自動で更新されます。

## ダウンロード

最新版は **[リリースページ](https://github.com/SametEge/Lokum/releases/latest)** から入手できます。

| ファイル | 対象 | 説明 |
| --- | --- | --- |
| `Lokum-Setup-<バージョン>-x64.exe` | Windows 10 / 11（64 ビット） | **おすすめ。** 現在のユーザーだけにインストールされ、管理者権限は不要。自動で更新されます。 |
| `Lokum-<バージョン>-win64.zip` | Windows ポータブル版 | 好きな場所（USB メモリーでも）に展開して `lokum.exe` を起動。更新があるとお知らせします。 |
| `Lokum-<バージョン>-linux-x86_64.tar.xz` | Linux（64 ビット） | 展開して `./lokum` を実行。`install-desktop-entry.sh` でアプリメニューに追加できます。 |
| `latest.json`、`SHA256SUMS.txt` | 全員 | 内蔵アップデーターが使う更新マニフェストと、全ファイルの SHA‑256 チェックサム。 |

> **Windows SmartScreen について。** Lokum はまだコード署名されていません（個人
> プロジェクトには証明書が高価なため）。そのため初回起動時に Windows が
> *「Windows によって PC が保護されました」* と表示することがあります。
> **詳細情報 → 実行** をクリックしてください。ファイルはいつでもリリースページの
> `SHA256SUMS.txt` と照合できます。

## おもな特長

- 🍬 **12 種類のフレーバー** — テーマはどれもロクムの一種：ローズ、ピスタチオ、レモン、ザクロ、オレンジ、ミント、ラベンダー、マスティック、ココナッツ、トルココーヒー、ミッドナイト、そして動く *アソート* の箱。どれもライトとダークのレシピ付き。
- 🧭 **Arc 風サイドバー _または_ クラシックタブ** — アドレスバーを内蔵した全高のサイドバー、Firefox の垂直タブ、あるいはおなじみのタブバー。いつでも切り替えられ、ウィンドウはその場で並び替わります。
- 🗂️ **スペース** — プライベート、仕事、学校、趣味を分けましょう。スペースごとにタブ、アイコン、フレーバー、（必要なら）コンテナーを持てます。スワイプか <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>←</kbd>/<kbd>→</kbd> で切り替え。
- ⌨️ **コマンドパレット**（<kbd>Ctrl</kbd>+<kbd>K</kbd>） — 開いているタブと 40 以上の操作をあいまい検索。アドレスバーをクリックすると大きな **フローティングコマンドバー** が開きます。
- 🎵 **ミニプレーヤー** — ほかのタブの音楽や動画を、サイドバーから再生・一時停止・スキップ・ミュート。
- 🧹 **自分で片付くタブ** — しばらく開いていないタブを自動アーカイブし、バックグラウンドのタブをスリープさせ、アーカイブからいつでも開き直せます。
- 🌟 **ほかにない歓迎ツアー** — 粉砂糖をまぶした 3D のロクムキューブを落としてフレーバーを選び、ウィザードの後ろでブラウザーが並び替わる様子を眺め、テンプレートからスペースを作り、前のブラウザーからインポートし、プライバシーのレベルを選択。紙吹雪つき。
- ⚙️ **使うのが楽しい設定画面** — 12 のセクション、即時検索、ライブプレビュー、Lokum 設定のエクスポート／インポート。
- 🔒 **最初からプライベート** — テレメトリーなし、調査なし、スポンサーコンテンツなし。厳格なトラッキング防止はワンクリック。uBlock Origin、セキュア DNS、HTTPS‑Only モード、GPC、フィンガープリント防止も設定に。
- 🌍 **12 の言語** — 英語、トルコ語、ドイツ語、フランス語、イタリア語、ロマンシュ語、スペイン語、スウェーデン語、韓国語、日本語、簡体字・繁体字中国語。Lokum にも Firefox 本体にも適用されます。
- 🔄 **自動アップデート** — 変更のたび、そして Mozilla が新しい Firefox を出すたびに GitHub Actions が新バージョンをビルドし、Lokum を閉じたときに静かにインストールします。
- 🦊 **中身は本物の Firefox** — Mozilla の公式ビルド、Gecko エンジン、すべての Firefox アドオン、Firefox Sync、そして公開と同時に届く Mozilla のセキュリティ修正。

## フレーバー

フレーバーはブラウザー全体を彩ります：ウィンドウの枠、サイドバー、ボタンや
スイッチのアクセントカラー、新しいタブのページ、そして Lokum 自身のページまで。
どのフレーバーにもライトとダークのレシピがあり、アクセントは好きな色に置き換え
られます。スペースごとにフレーバーを設定すれば、スペースを切り替えるとウィンドウの
色も変わります。

| | フレーバー | 雰囲気 |
| --- | --- | --- |
| 🌹 | **ローズ** | ローズウォーターの定番ロクム。ほんのり頬を染めたピンク。*（既定）* |
| 🌰 | **ピスタチオ** | みずみずしいピスタチオグリーン。落ち着いて集中できる色。 |
| 🍋 | **レモン** | 明るい朝にぴったりの、陽だまりのようなレモンピール。 |
| 🍎 | **ザクロ** | 深いザクロの赤。大胆でジューシー。 |
| 🍊 | **オレンジ** | オレンジとベルガモットのあたたかな輝き。 |
| 🌿 | **ミント** | 春風のように爽やかなクールミント。 |
| 💜 | **ラベンダー** | 夢見るような午後のための、やわらかなラベンダー。 |
| 🤍 | **マスティック** | クリーミーなマスティックアイボリー。静かで上品。 |
| 🥥 | **ココナッツ** | ココナッツホワイト。すっきりミニマル。 |
| ☕ | **トルココーヒー** | トルココーヒーの深いブラウン。 |
| 🌙 | **ミッドナイト** | 夜ふかしさんのための、星空のようなミッドナイトプラム。 |
| 🎨 | **アソート** | すべての色をゆっくりと巡る、ロクムの詰め合わせ。 |

テストがすべてのパレットを検査します：文字は枠の上で WCAG コントラスト 4.5:1、
アクセントボタンは 3:1 を満たす必要があり、ライトでもダークでも同様です。

オン／オフできる追加の演出：**粉砂糖**（サイドバーで小さくきらめく光）、
**やわらかな粒子**（さりげない紙の質感）、ページの角の丸み、枠の余白、ページの影、
インターフェースの密度（コンパクト／標準／ゆったり）、インターフェースのフォント
（システム／丸ゴシック／明朝体）、3 段階のアニメーション（すべて、控えめ — 色の
フェードは残り動きはなし — 、オフ）。OS の *視差効果を減らす* 設定にも従います。

## レイアウト：サイドバーかクラシックタブか

| レイアウト | 見た目 |
| --- | --- |
| **サイドバー（Arc スタイル）** *（既定）* | タブ、アドレスバー、ナビゲーションボタンが全高のサイドバーひとつにまとまります。ページはフレーバーの上に角丸のカードとして浮かび、その上の細いタイトルバーにページタイトル、サイト、*リンクをコピー* ボタンが表示されます。 |
| **垂直タブ** | Firefox 純正の垂直タブをサイドバーに、アドレスバーは上に。なじみやすく広々。 |
| **クラシックタブ** | どのブラウザーとも同じようにタブが上に — もちろんフレーバーの色で。 |

<p align="center">
  <img src="../images/screenshots/classic-tabs.webp" alt="クラシックタブとピスタチオのフレーバーの Lokum" width="80%">
</p>

そのほかのレイアウトオプション：

- **サイドバーの位置** — 左または右。
- **サイドバーを隠す（コンパクトモード）** — <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd>。ページがウィンドウ全体に広がり、ポインターが端に触れるとサイドバーがスライドして現れます。
- **フローティングコマンドバー** — Arc のように、アドレスバーがページ中央に大きく開きます。
- **新しいタブの位置** — リストの上または下。
- **タブの閉じるボタン** — ホバー時、常に表示、表示しない。
- **ピン留めしたタブはお気に入りに** — サイドバー上部に大きなアイコンのグリッドとして並び、どのスペースでも共通です。
- **ブックマークツールバー**、**ミニプレーヤー**、**ツールバーのカスタマイズ**。

## スペース

スペースは暮らしのいろいろな場面を分けてくれます。スペースごとに専用のタブ一覧、
名前、絵文字アイコン、そのスペースにいる間ウィンドウの色を変えるフレーバー（任意）、
そして Firefox の **コンテナー**（任意）を持てます。たとえば仕事スペースでは仕事用
アカウントにログインしたままにできます。

- サイドバー下部のアイコン、サイドバー上での **横スワイプ**（または <kbd>Shift</kbd> + ホイール）、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>←</kbd>/<kbd>→</kbd> で切り替え。<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd>…<kbd>9</kbd> で直接ジャンプも。
- **タブをスペースのアイコンにドラッグ** すると移動できます。タブのコンテキストメニューの *スペースに移動* も使えます。
- スペース名を右クリックすると、名前の変更、アイコン・フレーバー・コンテナーの変更、タブのクリア、スペースの作成と削除ができます。
- 並び順も含め、すべて **設定 → スペース** で管理できます。
- スペースはプロファイル（`lokum/spaces.json`）に保存され、各タブは再起動後も自分のスペースを覚えています。

## コマンドパレットとコマンドバー

どこでも <kbd>Ctrl</kbd>+<kbd>K</kbd>。数文字入力するだけで、Lokum が開いている
タブや操作をあいまい検索で見つけます：新しいタブ／ウィンドウ／プライベート
ウィンドウ、閉じたタブを開き直す、複製、ピン留め、リンクをコピー、直前のタブと
**分割表示**、リーダービュー、ピクチャーインピクチャー、スクリーンショット、ページ内
検索、印刷、ズーム、ダウンロード、履歴、ブックマーク、拡張機能、開発ツール、最近の
履歴を消去、ダークモード、すべてのレイアウト、すべてのフレーバー、すべての
スペース、Lokum や Firefox の設定。それ以外の入力はウェブ検索になります。

<p align="center">
  <img src="../images/screenshots/command-palette.webp" alt="ページ上のコマンドパレット" width="49%">

の候補、検索ショートカット、履歴をゆったりと。

## 自分で片付くタブ

- **自動アーカイブ** — 12 時間、1 日、1 週間、1 か月開いていないピン留めなしのタブを閉じて **アーカイブ** に保存します（最大 600 タブ）。**設定 → アーカイブ** やサイドバーのライブラリーボタンから検索して開き直せます。
- **スリープするタブ** — バックグラウンドのタブは数分後に解放してメモリーとバッテリーを節約でき、クリックすると戻ってきます。
- **ミニプレーヤー** — タブでメディアを再生中は、サイドバーの小さなカードにアートワーク、タイトル、アーティストと、前へ／再生・一時停止／次へ、ミュートが表示されます。
- さらに Firefox の機能もそのまま：**タブグループ**、**分割表示**、タブのプレビュー、自動 **ピクチャーインピクチャー**、セッションの復元。

## 歓迎ツアー

Lokum を初めて起動すると、ブラウザーの上に全画面の歓迎ツアーが開きます — そして
選ぶたびに、後ろのブラウザーがその場で変わっていきます。

<p align="center">
  <img src="../images/screenshots/welcome-flavor.webp" alt="歓迎ツアー：フレーバーを選ぶ" width="49%">
  <img src="../images/screenshots/welcome-layout.webp" alt="歓迎ツアー：レイアウトを選ぶ" width="49%">
</p>

1. **ようこそ** — 浮かぶ 3D のロクムキューブ、舞う砂糖、言語の切り替え。
2. **フレーバー** — 砂糖をまぶしたキューブが 12 個トレイに落ちてきます。ひとつタップすると粉砂糖がはじけ、ブラウザー全体の色が変わります。ライト、ダーク、自動を選ぶか、**おまかせ** でフレーバールーレットを。
3. **レイアウト** — Arc 風サイドバー、垂直タブ、クラシックタブ、サイドバーの位置とコンパクトモードをライブプレビュー。
4. **スペース** — プライベートから始めて、仕事・学校・趣味のテンプレートをワンタップで追加。
5. **インポート** — コンピューター上のほかのブラウザー（Chrome、Edge、Brave、Opera、Vivaldi…）を検出し、ブックマーク、パスワード、履歴などを取り込みます。
6. **プライバシー** — バランスまたは厳格なトラッキング防止、uBlock Origin、セキュア DNS。テレメトリーは常にオフ。
7. **完了** — 選んだ内容のまとめ、*Lokum を既定のブラウザーにする*、そして紙吹雪。

**設定 → 詳細 → ウェルカムツアー** からいつでもやり直せます。

## 設定

<kbd>Ctrl</kbd>+<kbd>,</kbd>、メインメニュー、サイドバー、または `about:lokum` の
入力で **Lokum の設定** を開けます。どのオプションもすぐに反映され、検索ボックスで
どの設定も名前で見つけられます。

| セクション | できること |
| --- | --- |
| **外観** | フレーバーギャラリー、ライト／ダーク／自動、カスタムアクセントカラー、粉砂糖、粒子、アニメーション、角の丸み、枠の余白、ページの影、密度、インターフェースのフォント。 |
| **レイアウト** | Arc サイドバー／垂直／クラシック、サイドバーの位置、コンパクトモード、フローティングコマンドバー、新しいタブの位置、閉じるボタン、ミニプレーヤー、ブックマークツールバー、ツールバーのカスタマイズ。 |
| **スペース** | スペースの有効化、スペースごとのウィンドウの色分け、スワイプで切り替え。スペースの追加・名前変更・アイコンとフレーバーの変更・並べ替え・削除、コンテナーの選択。 |
| **タブ** | 自動アーカイブ、スリープするタブ、起動時に復元、タブのプレビュー、タブグループ、分割表示、自動ピクチャーインピクチャー、終了前の確認。 |
| **アーカイブ** | アーカイブしたタブの検索・開き直し・削除、アーカイブを空にする。 |
| **プライバシーとセキュリティ** | バランス／厳格なトラッキング防止、ワンクリックで uBlock Origin、HTTPS‑Only モード、セキュア DNS（Cloudflare、Quad9、Mullvad、NextDNS、AdGuard…）、Global Privacy Control、フィンガープリント防止、終了時に履歴を消去、ポップアップブロック。 |
| **検索** | 既定の検索エンジン、検索候補、急上昇の検索、検索エンジンの管理。 |
| **ショートカット** | Lokum のすべてのショートカットと、サイトと重なるときにオフにするスイッチ。 |
| **言語** | インターフェースの言語（12 言語を同梱）、スペルチェック、ウェブサイトの優先言語。 |
| **更新** | 現在のバージョン、今すぐ確認、自動確認と自動インストール、安定版／ベータ版チャンネル、確認の間隔、リリースノート、すべてのリリース。 |

## プライバシー

Lokum は最初からプライベートで、ずっとそのままです：

- **テレメトリー、調査、クラッシュレポーター、既定のブラウザーエージェントはすべてなし。** エンタープライズポリシー（`distribution/policies.json`）で無効化され、パッケージからも取り除かれています。
- **スポンサーコンテンツなし** — 新しいタブにスポンサーのショートカットや記事はなく、Pocket も「おすすめ」の拡張機能や機能もありません。
- **強化型トラッキング防止** は既定で *バランス*、*厳格* はワンクリック。
- **uBlock Origin** は歓迎ツアーや設定からワンクリックでインストール。
- プライバシーセクションに **セキュア DNS** のプリセット、**HTTPS‑Only** モード、**Global Privacy Control**、**フィンガープリント防止**、**終了時に消去** があります。

Lokum 自身が接続する先：更新の確認のための `github.com` / `api.github.com`
（**設定 → 更新** でオフにできます）。それ以外はすべて通常の Firefox の動作 —
たとえばセーフブラウジングのリスト、証明書の失効データ、アドオンストア — で、
Firefox のプライバシー設定で管理できます。

## 自動アップデート

1. Lokum は 6 時間ごと（変更可能）に、最新の GitHub リリースから小さな `latest.json` を取得します。
2. 新しいバージョンがあれば、サイドバーにカードが表示され、インストーラーがバックグラウンドでダウンロードされます — GitHub のリリース配布サーバーからのみ。
3. ファイルの **SHA‑256** を `latest.json` と照合し、一致しないものは破棄します。
4. Lokum を閉じると、アップデートがバックグラウンドで静かにインストールされます。次に開いたときには新しいバージョンになっていて、*「Lokum が更新されました」* の通知からリリースノートを開けます。**再起動して更新** を押すと、すぐにインストールして Lokum を開き直します。

**設定 → 更新** で **安定版** か **ベータ版** のチャンネル、確認の間隔を選んだり、
自動インストールをオフにしたりできます。ポータブル zip 版はお知らせのみです。
Mozilla の Firefox アップデーターは無効化されています — 新しい Firefox は Lokum の
リリースが届けます。

## インストール

### Windows（インストーラー）

1. [最新リリース](https://github.com/SametEge/Lokum/releases/latest) から `Lokum-Setup-<バージョン>-x64.exe` をダウンロードします。
2. 実行し（上の SmartScreen の注意を参照）、言語、デスクトップショートカットの有無、Lokum を既定のブラウザーにするかを選んで **インストール** をクリックします。
3. Lokum は `%LOCALAPPDATA%\Programs\Lokum` にユーザー単位で、管理者権限なしでインストールされ、ブラウザーとして登録されます。**Windows の設定 → 既定のアプリ** で選択できます。

スクリプトでのインストール向けコマンドラインオプション：

| オプション | 意味 |
| --- | --- |
| `/S` | サイレントインストール |
| `/D=C:\パス\Lokum` | インストール先（最後に指定） |
| `/DESKTOP=0` | デスクトップショートカットを作らない（既定は `1`） |
| `/UBLOCK=0` | uBlock Origin をインストールしない（既定は `1`：初回起動時にインストール） |
| `/UPDATE` | 既存のインストールを更新（アップデーターが使用） |
| `/RELAUNCH` | 完了後に Lokum を起動 |

アンインストールは **Windows の設定 → アプリ → Lokum** から。アンインストーラーは
プロファイル（ブックマーク、パスワード、履歴）を残すか、一緒に削除するかを
たずねます。

### Windows（ポータブル版）

`Lokum-<バージョン>-win64.zip` を好きな場所に展開し、`lokum.exe` を起動します。
ポータブル版はレジストリーに触れず、更新はお知らせのみです。

### Linux

```sh
tar -xJf Lokum-<バージョン>-linux-x86_64.tar.xz
cd lokum
./lokum                      # 起動
./install-desktop-entry.sh   # 任意：アプリメニューに Lokum を追加
```

### データの保存場所

Lokum は、インストール済みの Firefox とは別の専用プロファイルを使います。
**設定 → 詳細 → プロファイルフォルダー** で開けます。Lokum 独自のデータ（スペース、
タブのアーカイブ）はプロファイル内の `lokum` フォルダーにあります。

## ソースからビルド

Lokum は Firefox をコンパイルしません。ビルドでは `archive.mozilla.org` から
**Firefox の公式リリース** をダウンロードし、Mozilla の `SHA512SUMS` で検証して
から Lokum に仕立てます。一般的なマシンなら Windows のフルビルドは数分で終わり、
Windows 用パッケージは Linux 上でもビルドできます。

**必要なもの**

- Python 3.10+
- Node.js 20+（[resedit](https://github.com/jet2jet/resedit-js) で `lokum.exe` のアイコンとバージョン情報を書き換え）
- Windows 版 Firefox インストーラーを展開するための `7z`（p7zip）、`tar`、`xz`
- Windows インストーラー用の NSIS 3（`makensis`）

Ubuntu/Debian の場合：`sudo apt install python3 nodejs npm p7zip-full nsis xz-utils`

**ビルド**

```sh
git clone https://github.com/SametEge/Lokum.git
cd Lokum
npm ci --prefix scripts/pe          # Windows ビルド用に一度だけ

# 最新の Firefox から Windows インストーラー + ポータブル zip
python3 scripts/build.py --platform win64

# 指定した Firefox バージョンで Linux 用アーカイブ
python3 scripts/build.py --platform linux-x86_64 --firefox-version 156.0
```

成果物は `dist/` に出力されます。便利なオプション：

| オプション | 意味 |
| --- | --- |
| `--platform {win64,win-arm64,linux-x86_64}` | 対象プラットフォーム |
| `--firefox-version X` | ベースにする Firefox のバージョン（既定：`firefox.json` の固定値、なければ最新） |
| `--version X` | Lokum のバージョン（既定：`version.json` + `-dev`） |
| `--firefox-dir フォルダー` | ダウンロードせず、展開済みの Firefox を使う |
| `--no-locales` | 言語パックをスキップ（高速） |
| `--no-installer` | NSIS をスキップ |
| `--app-only` | アプリフォルダーの準備後に停止 |

**展開済みの Firefox で開発する**

```sh
scripts/dev/install.sh /path/to/firefox        # Lokum のレイヤーをコピー
/path/to/firefox/firefox --profile /tmp/lokum-dev --no-remote
```

`src/lokum` の変更の多くは、ブラウザーを再起動するだけで反映されます。

**テスト**

```sh
node --test "tests/unit/*.test.mjs"      # コアロジック、フレーバーのコントラスト
python3 tests/check_locales.py --strict  # すべての辞書が揃っているか
node scripts/dev/make_content_css.mjs --check
LOKUM_SELFTEST=out.json ./lokum --headless   # ブラウザー内で 25 項目を検査
```

`LOKUM_SELFTEST` を指定すると、本物の Lokum がセルフテスト（レイアウト、スペース、
フレーバー、コマンドパレット、設定と歓迎ページ、言語、ブランディング、アップデーター、
ポリシー）を実行し、結果を JSON に書き出して終了します。CI は新しくビルドした
パッケージをインストールしたあと、Windows と Linux でこれを実行します。

## Lokum のしくみ

```
Firefox の公式リリース ──► SHA512 を検証 ──► 展開
        │
        ├─ Mozilla の言語パック 11 個を omni.ja に統合（+ 多言語リスト）
        ├─ Firefox のブランディング（名前、ロゴ、アイコン）を Lokum のものに置き換え
        ├─ Lokum のレイヤーを追加:  defaults/pref/lokum-autoconfig.js
        │                           lokum.cfg  （autoconfig のブートストラップ）
        │                           distribution/policies.json
        │                           browser/lokum/  （chrome://lokum パッケージ）
        ├─ アップデーター、クラッシュレポーター、テレメトリーを削除
        ├─ firefox.exe → lokum.exe、新しいアイコンとバージョン情報
        └─ パッケージ化: NSIS インストーラー · ポータブル zip · Linux アーカイブ
```

起動時に Firefox は `lokum-autoconfig.js` を読み、それが `lokum.cfg` を読み込み
ます。この小さなブートストラップが `chrome://lokum/` パッケージを登録し、ほかの
すべてをつなぐ `LokumStartup.sys.mjs` を起動します：

| モジュール | 役割 |
| --- | --- |
| `LokumStartup` | 起動／終了のフック、初回ツアー、「更新されました」通知、セルフテスト |
| `LokumWindow` | ウィンドウごとのコントローラー：スタイルシート、ルート属性、タイトルバー、コンパクトモード、フローティングコマンドバー、ショートカット |
| `LokumFlavors` | CSS の `light-dark()` 変数としての 12 のパレット |
| `LokumLayout` | Lokum のレイアウトを Firefox のサイドバー／垂直タブ設定とツールバー配置に変換 |
| `LokumSpaces` | スペース：保存、切り替え、サイドバーのヘッダーとフッター、メニュー、ドラッグ＆ドロップ |
| `LokumTabs` | 自動アーカイブとスリープするタブ |
| `LokumCommandPalette` | <kbd>Ctrl</kbd>+<kbd>K</kbd> のパレット |
| `LokumMediaCard` | サイドバーのミニプレーヤー |
| `LokumUpdater` | 更新の確認、検証済みダウンロード、終了時のサイレントインストール |
| `LokumI18n` | Lokum の辞書と初回起動時の言語選択 |
| `LokumShell` | Windows の既定のブラウザー連携 |
| `LokumContentStyles` | 新しいタブと Firefox の設定を、現在のフレーバーで装う |
| `LokumAboutPages` | `about:lokum`（設定）と `about:lokum-welcome`（ツアー） |
| `LokumSelfTest` | CI が使うブラウザー内セルフテスト |

リポジトリーの構成：

```
src/app/            Firefox の実行ファイルの隣にコピーされるファイル（autoconfig、ポリシー）
src/lokum/          chrome://lokum パッケージ
  modules/          JavaScript モジュール（上の表）
  styles/           ブラウザー UI のスタイル（トークン、枠、レイアウト、コンポーネント、アニメーション）
  pages/            about:lokum の設定と歓迎ツアー
  locales/          Lokum の辞書（12 言語）
  images/           アイコンとロゴ
scripts/build.py    ビルド（scripts/lokumbuild/ を参照）
scripts/release.py  リリース計画、latest.json、リリースノート
scripts/pe/         Windows 実行ファイルのリソース（resedit）
installer/          NSIS インストーラーとその翻訳
branding/           ロゴの元データと生成されたアイコン
tests/              単体テスト、言語チェック、スモークテスト
.github/workflows/  CI、ビルド、自動リリース
```

## リリースと継続的インテグレーション

- **すべてのプルリクエストとブランチへのプッシュ** で、単体テストと言語テストを実行し、Windows と Linux のパッケージをビルドし、本物の Windows・Linux ランナーにインストールしてブラウザー内セルフテストを行います。
- **`main` へのプッシュ** では同じ処理のあと、インストーラー、ポータブル zip、Linux アーカイブ、`latest.json`、`SHA256SUMS.txt`、自動生成のリリースノートを含む **新しい GitHub リリース** を公開します。インストール済みの Lokum はそこから自動更新されます。
- **6 時間ごと** に定期ジョブが Mozilla に最新の Firefox バージョンを問い合わせ、前回のリリースより新しければ、その上で Lokum を再ビルドして自動公開します — 誰も手を動かさなくてもセキュリティ修正が届きます。
- リリースは手動でも開始できます（**Actions → Release → Run workflow**）。Firefox のバージョン指定やベータのプレリリースも可能です。

バージョン番号は `version.json` から決まり、リリースごとにパッチ番号が自動で
上がります。必要なら `firefox.json`（`{"version": "156.0"}`）で Firefox の
バージョンを固定できます。

## よくある質問

**Lokum は Firefox のフォークですか？**
別エンジンという意味ではフォークではありません。Lokum は Mozilla の公式 Firefox
ビルドを再パッケージし、独自のインターフェースのレイヤーを加えています。そのため
Firefox のエンジン、性能、ウェブ互換性、セキュリティ修正をそのまま得られます。

**Firefox の拡張機能は使えますか？**
はい — [addons.mozilla.org](https://addons.mozilla.org) のアドオンはすべて使えます。

**Firefox Sync は使えますか？**
はい。**Firefox の設定 → Sync** からログインすると、ブックマーク、パスワード、履歴、
タブ、アドオンをほかのデバイスの Firefox と同期できます。

**Lokum は既存の Firefox を変更したり読み取ったりしますか？**
いいえ。Lokum は専用のプロファイルを使います。データを移したい場合はインポートの
ステップ（または **設定 → 詳細 → インポート**）を使ってください。

**ウイルス対策ソフトや SmartScreen が警告するのはなぜ？**
インストーラーがまだコード署名されていないためです。リリースページの
`SHA256SUMS.txt` とファイルを照合するか、Lokum を自分でビルドしてください。

**macOS 版はありますか？**
まだありません。Windows と Linux は変更のたびにビルド・テストされています。

**更新後に表示がおかしくなりました。リセットするには？**
**設定 → 詳細 → Lokum の設定をリセット** で Lokum のオプションをすべて既定値に
戻せます。タブ、スペース、データはそのまま残ります。
